## Execution order

1. **001** — smallest, highest leverage; removes the card-wide blur and main-thread slide.
2. **002** — removes the 336 JS-driven cell animations (the biggest main-thread cost).
3. **003** — requires 001 and 002 (it verifies the reduced-motion branch written in 002).
4. **004** — independent of the others but touches the file 003's feel check exercises, so do it after 003.
5. **005** — only after 001–004, and only if a recording still shows jank (Step 0 gate); otherwise mark WONTFIX.

## Dependencies

- 003 depends on 001 and 002.
- 005 depends on 001–004 (gate).
- 001, 002 and 004 edit different files and can be run in parallel by separate agents; 003 edits
  `index.tsx` like 001, so run 003 after 001 lands to avoid conflicts.

## Not planned (by design)

- The package-wide `[0.16, 1, 0.3, 1]` curve and the dropped per-cell blur are deliberate.
- No `will-change` anywhere: nothing here shows a hand-off shift.
- Lower-priority audit items (refresh-icon easing/press feedback; hover handler layout reads and
  per-hover re-render of cell elements) were not selected; revisit with `improve-animations reconcile`.
