Les composants sont des éléments d'interface unitaires (bouton, champ, carte, dialogue...) prêts à
être installés dans votre projet via la CLI shadcn.

## Utilisation

Parcourez la liste dans la barre latérale pour voir un aperçu de chaque composant, son code source
et ses props disponibles.
