**Whoa Stash** est une application macOS construite autour d'une idée simple :

> **Les contrôles que vous utilisez tous les jours ne devraient pas vous encombrer toute la journée.**

Stash ajoute une couche de contrôle invisible autour de votre Mac. Au lieu de remplir l'écran de contrôles permanents, tout reste caché jusqu'à ce que vous alliez le chercher.

Contrôlez **le volume, la luminosité, l'apparence, le rétroéclairage du clavier, la sortie audio et vos apps** directement depuis les bords et les coins de l'écran.

L'expérience est pensée pour paraître native sur macOS : animations discrètes, interactions tactiles, retours haptiques du trackpad et transitions soignées donnent à chaque interaction une sensation physique.

## Fonctionnalités

### Edge Sliders

Faites apparaître des contrôles directement depuis le bord gauche ou droit de l'écran.

Utilisez-les pour :

- 🔊 le volume
- ☀️ la luminosité
- 🌓 l'apparence
- et d'autres contrôles système

  <img src="/assets/projects/whoa-stash/edge-slider.png" width="700" alt="Edge Slider" />

### Corner Dials

Transformez les coins de l'écran en molettes tactiles.

Les Corner Dials offrent une façon compacte et agréable de régler par exemple :

- le volume
- la luminosité
- le rétroéclairage du clavier
- la sortie audio

  <img src="/assets/projects/whoa-stash/corner-dial.png" width="700" alt="Corner Dial" />

### Hidden Dock

Gardez vos apps secondaires à portée de main sans surcharger votre Dock habituel.

Approchez-vous du bord du Dock et Stash révèle en douceur vos apps cachées.

Le Dock de macOS reste intact : Stash fonctionne simplement à côté.

<img src="/assets/projects/whoa-stash/hidden-dock.png" width="700" alt="Hidden Dock" />

### Profils par app

Vos contrôles peuvent s'adapter automatiquement à l'application en cours d'utilisation.

Créez des profils qui modifient :

- les apps du Hidden Dock
- les Edge Sliders
- les Corner Dials
- la configuration des contrôles

Par exemple :

```text
Visual Studio Code
    ├── Hidden Dock → Terminal, GitHub, Safari
    ├── Bord gauche → Luminosité
    └── Coin        → Volume

Spotify
    ├── Hidden Dock → Musique, Messages
    ├── Bord gauche → Volume
    └── Coin        → Sortie audio
```

Les contrôles proposent :

- des animations fluides

## Philosophie de design

Whoa Stash suit un principe simple :

### Caché par défaut.

L'interface ne doit pas entrer en concurrence avec l'application que vous utilisez.

Stash n'apparaît donc que lorsque vous allez volontairement le chercher.

```text
┌─────────────────────────────────────────────┐
│                                             │
│                                             │
│             Votre application               │
│                                             │
│                                             │
│                                             │
│                                             │
│                                  ◉          │
│                                             │
└─────────────────────────────────────────────┘
       ↑                             ↑
   Edge Slider                  Corner Dial
```

Le résultat : une couche de contrôle qui fait partie de macOS plutôt qu'une fenêtre d'application de plus.

## Prérequis

- macOS Tahoe ou plus récent
- Mac Apple Silicon ou compatible
- Trackpad recommandé pour profiter de l'expérience tactile complète

> Stash est conçu spécifiquement autour des interactions système de macOS et de son interface basée sur les bords de l'écran.

### Configuration

Après avoir lancé Stash :

1. Configurez les apps de votre Hidden Dock.
2. Choisissez les contrôles à afficher sur chaque bord.
3. Configurez vos Corner Dials.
4. Créez des profils par app si besoin.
5. Utilisez Stash directement depuis les bords de l'écran.

Une fois configurée, l'interface reste en retrait jusqu'à ce que vous en ayez besoin.

## Architecture

Whoa Stash est conçu comme une expérience macOS native, avec un accent particulier sur :

- les API système natives
- des animations fluides
- une interface minimale
- des interactions sans friction
- l'accessibilité
- les contrôles au niveau du système
- les retours tactiles

L'application repose volontairement sur de petites interactions ciblées plutôt que sur de grandes interfaces permanentes.

## Philosophie

Whoa Stash n'a pas vocation à remplacer les contrôles de macOS.

Il est conçu pour les rendre **plus agréables**.

Au lieu d'ouvrir le Centre de contrôle, de fouiller dans les menus ou de garder des apps en permanence à l'écran, Stash place ce que vous utilisez le plus exactement là où votre main va naturellement.

**Invisible quand vous n'en avez pas besoin.
Immédiat quand vous en avez besoin.**
