## Animation

La carte grandit depuis son déclencheur en 180 ms.

Les jetons et les règles communes sont décrits sur la page [Motion](/ui/components/core/motion).

## Installation

Le composant fait partie des primitives shadcn/ui sur Base UI.

```bash
bunx --bun shadcn@latest add hover-card
```

Ou depuis le paquet npm :

```tsx
import { HoverCard } from '@whoa-studio/ui/hover-card';
```

Exports : `HoverCard, HoverCardTrigger, HoverCardContent`.
