## Animation

La pastille glisse en 180 ms et la piste change de couleur en 120 ms.

Les jetons et les règles communes sont décrits sur la page [Motion](/ui/components/core/motion).

## Installation

Le composant fait partie des primitives shadcn/ui sur Base UI.

```bash
bunx --bun shadcn@latest add switch
```

Ou depuis le paquet npm :

```tsx
import { Switch } from '@whoa-studio/ui/switch';
```

Exports : `Switch`.
