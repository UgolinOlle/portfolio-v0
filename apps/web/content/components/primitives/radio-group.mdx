## Animation

Le point apparaît avec un fondu et un zoom de 120 ms ; la bordure suit.

Les jetons et les règles communes sont décrits sur la page [Motion](/ui/components/core/motion).

## Installation

Le composant fait partie des primitives shadcn/ui sur Base UI.

```bash
bunx --bun shadcn@latest add radio-group
```

Ou depuis le paquet npm :

```tsx
import { RadioGroup } from '@whoa-studio/ui/radio-group';
```

Exports : `RadioGroup, RadioGroupItem`.
