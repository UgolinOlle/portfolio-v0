## Core curriculum

- **[libft](https://github.com/UgolinOlle/libft)** — Recreation of standard C library functions + utilities.
- **[ft_printf](https://github.com/UgolinOlle/ft_printf)** — Reimplementation of the `printf` function.
- **[get_next_line](https://github.com/UgolinOlle/get_next_line)** — Function to read a file line by line.
- **[fract-ol](https://github.com/UgolinOlle/fract-ol)** — First graphics project (2D fractals).
- **[NetPractice](https://github.com/UgolinOlle/NetPractice)** — Networking / IP routing exercises.
- **[minitalk](https://github.com/UgolinOlle/minitalk)** — Client/server communication via UNIX signals.
- **[push_swap](https://github.com/UgolinOlle/push_swap)** — Stack sorting with a limited set of operations.
- **[philosophers](https://github.com/UgolinOlle/philosophers)** — Dining philosophers problem (threads / concurrency).
- **[minishell](https://github.com/UgolinOlle/minishell)** — Minimal bash-like shell.

## Advanced projects

- **[miniRT](https://github.com/UgolinOlle/miniRT)** — Minimal ray tracer for rendering 3D scenes.

## Other

- **[charger-detector](https://github.com/UgolinOlle/charger-detector)** — Charger detection on macOS / Linux (Asahi-related).
- **[c_formatter_42](https://github.com/UgolinOlle/c_formatter_42)** (fork) — norminette-compliant C formatter (tool for 42).
