# API contracts

There is no backend service. The public surface is the static/generated files and route handlers served by `apps/web`, plus the npm package. When one changes, update this file in the same change.

## Registry item contract

Source of truth: `packages/<item>/package.json` → `registry` field, validated by `packages/ui/scripts/registry.ts`.

- `name` must be `@portfolio-v0/<dir>`; `description` is required.
- `registry.type`: `ui` (single `index.tsx` → `components/ui/ugolin/<name>.tsx`) or `block` (→ `components/blocks/<name>/`); `category: "template"` marks a template.
- `dependencies` must equal the bare npm imports of the sources (minus react, react-dom and `@portfolio-v0/*`); the generator fails on any mismatch.
- Every item gets `<name>-demo` item(s) from `apps/web/examples/<example>.tsx`.
- Dependencies between items are URLs: `https://ugolin-olle.com/r/<item>.json`.

## Errors

- `registry:generate` prints `registry.json non généré :` plus one line per violation (prefixed `packages/<name>:`) and exits 1; nothing is written.
- Route handlers do not define a custom error shape; Next.js defaults apply (404 via `not-found.tsx`).

## Versioning

`@ugolin-olle/ui` follows semver (`npm version <patch|minor|major> --no-git-tag-version` in `packages/ui`, then `bun publish`, not `npm publish`: bun rewrites `workspace:*`). Registry URLs under `/r/` track the deployed site and are not versioned; renaming or removing an item is a breaking change for consumers.
