## Animation

Hauteur et opacité transitent ensemble (240 ms en entrée, 180 ms en sortie).

Les jetons et les règles communes sont décrits sur la page [Motion](/ui/components/core/motion).

## Installation

Le composant fait partie des primitives shadcn/ui sur Base UI.

```bash
bunx --bun shadcn@latest add collapsible
```

Ou depuis le paquet npm :

```tsx
import { Collapsible } from '@whoa-studio/ui/collapsible';
```

Exports : `Collapsible, CollapsibleTrigger, CollapsibleContent`.
