# portfolio-v0

Portfolio of Ugolin Ollé (French default, English via `?lang=en`) and a shadcn-style UI registry (`@ugolin-olle/ui`), both served by one Next.js 16 / Fumadocs site in `apps/web`. Each registry item is its own `packages/<name>/` workspace package.

<!-- claude-kit:begin stack -->

## Stack

- TypeScript on Bun (package manager: bun)
- Monorepo (workspaces + turbo), 19 packages: `apps/web`, `packages/activity`, `packages/avatars`, `packages/blog`, `packages/button`, `packages/button-apple`, `packages/button-gandi`, `packages/button-shopify`, `packages/calendar-sync`, `packages/config`, `packages/cta-simple`, `packages/headers`, … (+7 more)

## Commands

```bash
bun install     # install
bun run dev     # dev
bun run build   # build
bun run check-types  # typecheck (all workspaces)
bun run check   # check
bun run format  # format
```

## Conventions

- `packages/ui/registry.json` is generated by `packages/ui/scripts/registry.ts`; never hand-edit it. After touching a `packages/<item>`, run `bun run --cwd packages/ui registry:generate` and commit the result.
- Registry item sources import shared code only via `@/lib/utils`, `@/components/ui/<x>`, `@/components/ui/ugolin/<x>`, `@/components/blocks/<x>`. Add `'use client';` to files using hooks/state/handlers.
- Adding an item = package + `apps/web/examples/<name>.tsx` + docs page with `preview: <name>`. Steps in `CONTRIBUTING.md`.
- Projects and writings are bilingual: `<name>.mdx` (fr, default) and `<name>.en.mdx`. Home page strings live in `apps/web/src/locales/{fr,en}/common.json`; keep both in sync.
- Lint/format is oxlint + oxfmt (not eslint/prettier). `bun run check` rewrites files; run type checks with `bun run check-types`.

<!-- claude-kit:begin workflow -->

## Workflow

- **Plan first.** For changes touching more than ~3 files, start in Plan Mode (Shift+Tab), agree on the plan, then edit.
- **Decompose.** Split big tasks into steps that each end green (tests/typecheck pass) before starting the next.
- **Search, then read.** Grep/glob for the symbol you need instead of opening whole directories or large files.
- **Verify.** Run the relevant test/lint command before calling a task done.

## Guardrails

- Paths in `.claudeignore` are blocked from reading via `permissions.deny` in `.claude/settings.json`. Don't work around it with shell commands; ask if you need one of them.
- Lockfiles, build output and `.env*` files are edit-protected by `.claude/hooks/pre-edit.cjs`. Change the source of truth instead (manifest, sources).

## Gotchas

- There is no test runner (no root `test` script); rely on `bun run check-types` and `bun run check`. CI (`.github/workflows/ci.yml`) runs lint, format check and type checks.
- Shared dependency versions (react, motion, lucide-react, typescript, …) live in the root `workspaces.catalog`; reference them as `"catalog:"` in manifests. `bun run bump-deps` does not update the catalog; edit it by hand.
- Shared tsconfig presets and the oxlint base config live in `packages/config`.
- `apps/web` runs `registry:build` before `dev`/`build`; restart dev to pick up registry changes. `.source/` is generated by `fumadocs-mdx` (`postinstall`).
- A new project/writing page must also be listed in its folder's `meta.json` to appear in the tree.
- Use `bun publish` (not `npm publish`) for `packages/ui`: it rewrites `workspace:*`.
- `.claude/` is in `.claudeignore`, so Claude cannot read `.claude/settings.json` or `.claude/context/*` here; ask the user to paste or un-ignore them when needed.
