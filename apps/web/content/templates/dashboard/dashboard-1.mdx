Le template `Dashboard 1` est une boîte de réception d'approbations : barre de navigation, en-tête
avec statistiques, liste filtrable (onglets et recherche) et panneau de détail avec chronologie du
workflow, barre de budget, preuves et actions de décision.

## Installation en CLI

```bash
npx @whoa-studio/templates add dashboard-1
```

## Utilisation

Passez vos `approvals`, vos `details` (contenu complet, indexé par identifiant) et vos `stats`.
Sans props, le composant affiche des données de démonstration.
