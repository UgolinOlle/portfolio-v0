Les blocks sont des sections de page complètes (hero, blog, footer...) prêtes à copier-coller dans
votre projet. Contrairement aux composants, ils combinent plusieurs éléments d'interface pour
former une section fonctionnelle.

## Utilisation

Parcourez la liste dans la barre latérale pour voir un aperçu de chaque block, son code source et
ses props disponibles.
