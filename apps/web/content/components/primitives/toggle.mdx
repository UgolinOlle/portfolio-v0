## Animation

Même retour d'appui que `Button` (`scale(0.97)`, 120 ms) et couleur animée entre les états.

Les jetons et les règles communes sont décrits sur la page [Motion](/ui/components/core/motion).

## Installation

Le composant fait partie des primitives shadcn/ui sur Base UI.

```bash
bunx --bun shadcn@latest add toggle
```

Ou depuis le paquet npm :

```tsx
import { Toggle } from '@whoa-studio/ui/toggle';
```

Exports : `Toggle`.
