Le block `Blog7` affiche une section complète de blog : titre, description et une grille
d'articles sous forme de cartes responsives (image, auteur, date, résumé).

## Utilisation

Passez vos propres articles via la prop `posts`, ou laissez les valeurs par défaut pour un aperçu
rapide.
