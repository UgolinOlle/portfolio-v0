Cette configuration se trouve dans `nvim/` au sein de mon monorepo [dotfiles](https://github.com/UgolinOlle/dotfiles), aux côtés de mes outils shell, terminal et macOS.

## Points forts

- **Thème adaptatif au système** — lit `AppleInterfaceStyle` de macOS au démarrage et bascule automatiquement entre `github_dark` / `github_light` (même logique de détection réutilisée pour l'ombrage de `toggleterm`)
- **Chaîne d'outils JS/TS orientée oxc** — [oxlint](https://oxc.rs/docs/guide/usage/linter) pour le linting et un formateur `oxfmt` personnalisé branché sur conform.nvim, avec [typescript-tools.nvim](https://github.com/pmizio/typescript-tools.nvim) pilotant une instance `tsserver` rapide (pas de `ts_ls` via Mason) et des commandes dédiées à l'auto-import
- **Tableau de bord personnalisé** — l'écran d'accueil NvDash est réécrit pour lister les fichiers récents et les _projets_ récents (suivis via une autocommande) avec des raccourcis à une seule lettre
- **Navigation consciente de Zellij** — `<C-hjkl>` déplace le focus entre les splits Neovim et les panneaux Zellij de manière transparente
- **Interface Noice ajustée** — la ligne de commande, le popupmenu et le hover/signature LSP passent par [noice.nvim](https://github.com/folke/noice.nvim), avec filtrage des messages de progression LSP bruyants et des "aucun résultat"
- **Discord Rich Presence** — activable à la demande avec `:DiscordRichPresence` (encapsule [cord.nvim](https://github.com/vyfor/cord.nvim))
- **Outils gérés par Mason** — serveurs LSP, linters et formateurs sont déclarés une seule fois dans `chadrc.lua` et installés automatiquement

## Prérequis

- **Neovim** >= 0.10.0
- **Git**
- **Nerd Font** (JetBrains Mono, défini comme `guifont`)
- **Node.js** (pour les serveurs LSP)
- **ripgrep** (recherche live Telescope)
- **[Zellij](https://zellij.dev/)** (optionnel, pour la navigation entre panneaux)

## Installation

Cette configuration fait partie d'un repo dotfiles plus large, donc `nvim/` est un sous-répertoire plutôt qu'une racine de repo autonome.

```bash
# Sauvegarder la configuration existante
mv ~/.config/nvim ~/.config/nvim.bak
mv ~/.local/share/nvim ~/.local/share/nvim.bak

# Cloner le repo dotfiles et créer un lien symbolique vers la config nvim
git clone git@github.com:UgolinOlle/dotfiles.git ~/dotfiles
ln -s ~/dotfiles/nvim ~/.config/nvim

# Démarrer Neovim — les plugins et outils Mason s'installent automatiquement
nvim
```

## Structure

```
nvim/
├── init.lua                 # Point d'entrée, bootstrap lazy.nvim
├── .stylua.toml             # Règles de formatage Lua
├── .neoconf.json             # Paramètres neodev/neoconf pour lua_ls
├── lua/
│   ├── chadrc.lua           # Config NvChad : détection de thème, UI, liste d'outils Mason
│   ├── options.lua          # Options Vim
│   ├── mappings.lua         # Raccourcis clavier
│   ├── autocmds.lua         # Autocommandes
│   ├── commands.lua         # Commandes utilisateur personnalisées (DiscordRichPresence)
│   ├── configs/
│   │   ├── conform.lua      # Configuration des formateurs (oxfmt, prettier, stylua...)
│   │   ├── lspconfig.lua    # Configuration des serveurs LSP + raccourcis d'import
│   │   ├── lint.lua         # Configuration nvim-lint (oxlint)
│   │   ├── noice.lua        # Interface Noice + filtrage des messages
│   │   ├── nvdash.lua       # Tableau de bord personnalisé (fichiers/projets récents)
│   │   ├── lazy.lua         # Options de lazy.nvim
│   │   ├── cmp.lua          # Configuration de la complétion
│   │   └── luasnip.lua      # Configuration des snippets
│   └── plugins/
│       ├── init.lua         # Spécifications des plugins
│       ├── telescope.lua    # Configuration Telescope + ui-select
│       └── gitgraph.lua     # Plugin de graphe git
```

## Raccourcis clavier

Touche leader : `Espace`

### Général

| Touche             | Mode | Action                                  |
| ------------------ | ---- | --------------------------------------- |
| `<leader>w`        | n    | Enregistrer le fichier                  |
| `Q`                | n    | Fermer la fenêtre                       |
| `;`                | n    | Entrer en mode commande                 |
| `jk` / `kj`        | i    | Quitter le mode insertion               |
| `<leader><leader>` | n    | Rechercher des fichiers (Telescope)     |
| `sv` / `ss`        | n    | Diviser verticalement / horizontalement |
| `<leader>b`        | n    | Nouveau buffer                          |
| `<leader>th`       | n    | Changer de thème (Telescope)            |
| `<leader>nn`       | n    | Fermer les notifications (Noice)        |

### LSP & Imports

| Touche                      | Mode | Action                                                                |
| --------------------------- | ---- | --------------------------------------------------------------------- |
| `K`                         | n    | Documentation au survol (bordure arrondie)                            |
| `<leader>ca`                | n    | Actions de code                                                       |
| `<leader>fm`                | n, v | Formater le fichier / la sélection                                    |
| `<leader>dy`                | n    | Copier le diagnostic sous le curseur dans le presse-papiers           |
| `<leader>ih`                | n    | Basculer les inlay hints                                              |
| `<leader>l`                 | n    | Déclencher le lint                                                    |

| `<leader>to` / `<leader>ts` | n    | Organiser les imports / trier les imports (TS)                        |

## Formatage & Linting

Le formatage et le linting JS/TS s'appuient sur [oxc](https://oxc.rs/) pour la rapidité ; tout le reste utilise Prettier ou des formateurs dédiés. Le format à la sauvegarde est activé via conform.nvim (`configs/conform.lua`), le linting s'exécute sur `BufEnter` / `BufWritePost` / `InsertLeave` via nvim-lint (`configs/lint.lua`).

| Langage                           | Formateur     | Linter   |
| --------------------------------- | ------------- | -------- |
| Lua                               | `stylua`      | —        |
| JavaScript/TypeScript (+ JSX/TSX) | `oxfmt` (oxc) | `oxlint` |
| JSON/JSONC                        | `prettier`    | —        |
| HTML/CSS                          | `prettier`    | —        |
| Markdown                          | `prettier`    | —        |
| YAML                              | `prettier`    | —        |
| SQL                               | `sqlfmt`      | —        |
| Shell (sh/bash/zsh)               | `shfmt`       | —        |

## Personnalisation

### Thème

Le thème se synchronise automatiquement avec l'apparence système de macOS (`lua/chadrc.lua`). Pour fixer un thème manuellement :

```lua
-- lua/chadrc.lua
M.base46 = {
  theme = "github_dark", -- ou n'importe quel thème NvChad
}
```

### Ajouter des serveurs LSP

```lua
-- lua/configs/lspconfig.lua
local servers = {
  "html",
  "cssls",
  -- ajoutez votre serveur ici
}
```

### Ajouter des formateurs

```lua
-- lua/configs/conform.lua
formatters_by_ft = {
  python = { "black" },
  -- ajoutez votre formateur ici
}
```
