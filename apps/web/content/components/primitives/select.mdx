## Animation

La liste grandit depuis le déclencheur en 180 ms ; quand elle s'aligne sur la valeur courante, elle apparaît sans transition.

Les jetons et les règles communes sont décrits sur la page [Motion](/ui/components/core/motion).

## Installation

Le composant fait partie des primitives shadcn/ui sur Base UI.

```bash
bunx --bun shadcn@latest add select
```

Ou depuis le paquet npm :

```tsx
import { Select } from '@whoa-studio/ui/select';
```

Exports : `Select, SelectTrigger, SelectValue, SelectContent, SelectItem`.
