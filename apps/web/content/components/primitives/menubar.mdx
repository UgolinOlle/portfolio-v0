## Animation

Les menus grandissent depuis leur déclencheur en 180 ms ; passer d'un menu à l'autre est immédiat.

Les jetons et les règles communes sont décrits sur la page [Motion](/ui/components/core/motion).

## Installation

Le composant fait partie des primitives shadcn/ui sur Base UI.

```bash
bunx --bun shadcn@latest add menubar
```

Ou depuis le paquet npm :

```tsx
import { Menubar } from '@whoa-studio/ui/menubar';
```

Exports : `Menubar, MenubarMenu, MenubarTrigger, MenubarContent, MenubarItem`.
