## Animation

La coche apparaît avec un fondu et un léger zoom de 120 ms ; la couleur de fond et de bordure suit le même rythme.

Les jetons et les règles communes sont décrits sur la page [Motion](/ui/components/core/motion).

## Installation

Le composant fait partie des primitives shadcn/ui sur Base UI.

```bash
bunx --bun shadcn@latest add checkbox
```

Ou depuis le paquet npm :

```tsx
import { Checkbox } from '@whoa-studio/ui/checkbox';
```

Exports : `Checkbox`.
