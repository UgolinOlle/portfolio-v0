Le template `App Shell 1` fournit la structure d'une application : sidebar repliable avec sélecteur
d'espace de travail, navigation groupée avec sous-menus, menu utilisateur, header collant avec
fil d'Ariane et recherche, puis une zone de contenu.

## Installation en CLI

```bash
npx @whoa-studio/templates add app-shell-1
```

## Utilisation

Passez vos `workspaces`, votre `nav` et votre `user`, puis affichez votre page en `children`.
